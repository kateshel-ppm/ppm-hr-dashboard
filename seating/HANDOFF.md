## 2. Доступ

Сервисный аккаунт `claude-assistant@claude-assistant-for-kateshel.iam.gserviceaccount.com`,
проект GCP `claude-assistant-for-kateshel`. Sheets API и Drive API включены.
Обе таблицы расшарены на него как редактор.

Скрипты берут ключ из `GOOGLE_SA_KEY` (JSON одной строкой) или `GOOGLE_SA_KEY_FILE` (путь).
**В переписку попал полный JSON ключа `d1f0841…` — его нужно отозвать и выпустить новый.**
Положить новый в переменную окружения сессии, не в чат.

Сеть: `sheets.googleapis.com`, `oauth2.googleapis.com`, `www.googleapis.com` доступны.
`script.google.com` и `docs.google.com` заблокированы политикой — Apps Script и
per-gid PDF-экспорт недоступны. PDF всей книги: Drive API `files/{id}/export`.

## 3. Источник данных для рассадок

Объединённый, решение заказчика:
- **люди и должности** — из `ШТАТКА` (156 строк);
- **вакансии** — 15 строк из `Штат 21 09 26`;
- **сохранены** 5 человек, которых нет в ШТАТКЕ, но они есть в переезде и на схеме:
  Липцина, Назаренко, Натали, Шияфетдинов, Малютин.

Собирает `merge_source.py` → `shtat.tsv` в 12-колоночной раскладке `Штат 21 09 26`.
Все сборщики читают `shtat.tsv`. Индексы колонок:
`0 №, 1 Офис(крыло), 2 Кабинет, 3 ФИО, 4 Проект, 5 Грейд, 6 Должность, 7 Отдел,
8 Статус, 9 Формат работы, 10 Город, 11 Прямой руководитель`.

Правила отбора: место нужно, если `Город = Москва` и `Формат ∈ {Офис, Гибрид}`.
Вакансия: `ФИО = Вакансия` или `Статус = Вакансия`.

Алиасы, заданные в коде:
- `Отдел контроля качества` → `ОКК` (ШТАТКА называет иначе)
- `Гладкова Алёна` (переезд, схема) = `Гладкова Елена` (ШТАТКА) — одно лицо
- C-level: колонка «Грейд» = `С-level` в `Штат 21 09 26`, плюс по должности `CTO` и `HRD`

Что в ШТАТКЕ отличается от переезда и уже учтено: Зеленин, Петров А.Д. — офис
(были удалённо); Абдуназаров — гибрид; Архангельский — отдел АУП, не AI.

## 9. Как перестроить

```bash
cd seating
export GOOGLE_SA_KEY_FILE=/path/to/key.json     # или GOOGLE_SA_KEY='{...}'
pip install cryptography pymupdf                 # cryptography системная сломана — --ignore-installed

python3 fetch_sources.py            # Штат 21 09 26 → shtat_now.tsv, ШТАТКА → shtatka.tsv, merge → shtat.tsv
python3 build_and_format.py && python3 polish.py   # Рассадка по отделам 21.09.26
python3 build_variant.py            # Рассадка — все в новом офисе
python3 build_analytics.py          # Кол-во сотрудников (читает вкладки рассадок)
python3 build_plan_analytics.py     # Аналитика — нужен plan.pdf рядом
python3 build_current.py            # Текущая рассадка
python3 build_proposal.py           # Рассадка — предложение
python3 build_full_move.py          # Рассадка — новый офис (полный переезд), ёмкости кабинетов в ROOMS
python3 build_full_move.py --marketing-stays   # Рассадка — новый офис (без маркетинга)
python3 build_stay.py               # Остоженка — кто остаётся (состав из stay_rules.py, вариант 2)
```

Каждый сборщик после записи перечитывает вкладку и сверяет с отправленным;
падает с `AssertionError` при расхождении. `build_proposal.py` дополнительно
проверяет, что кабинеты не переполнены и все C-level размещены.

Правки рассадки — в `PLAN` внутри `build_proposal.py`: список
`(кабинет, [люди])`, порядок важен, `take()` забирает всех оставшихся из
отдела, `take_named()` — конкретных.

## 10. Грабли Sheets API, на которые уже наступали

- **Слияния снимать ДО записи значений.** Запись в объединённый диапазон
  сохраняет только верхнюю левую ячейку, остальное молча теряется.
- `mergeCells` не пересекает границу закреплённых колонок — сначала
  `frozenColumnCount: 0`.
- Диапазон формата за пределами сетки → 400. Размер листа перечитывать
  **после** записи, она расширяет лист. Хвост чистить только если `N < rowCount`.
- `mergeType` = `MERGE_ALL`, не `MERGE_ROW`. `hideGridlines` внутри `gridProperties`.
- Заливка сбрасывается `repeatCell`, рамки — нет: `updateBorders` со `style: NONE`.
- Кириллица в URL — через `quote()` из `sheets_write.py`.
- `values.get` обрезает хвостовые пустые ячейки — дополнять до нужной ширины.
- Markdown-экспорт Drive-коннектора теряет колонки (потерял «Грейд») —
  читать только через Sheets API.
